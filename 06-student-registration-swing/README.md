# Student Registration Form (Java Swing)

A desktop GUI form application built using Java Swing with comprehensive client-side form validation.

## 🎯 Features

- **Form Fields:** Name, Roll Number, Branch, Gender (`JRadioButton` with `ButtonGroup`), and Terms & Conditions checkbox.
- **Form Actions:**
  - **Submit Button:** Validates all mandatory fields, ensures terms are agreed to, and displays a summary dialog.
  - **Reset Button:** Clears all fields and resets selections.

## ▶️ Compilation & Execution

Compile:
```bash
javac StudentRegistration.java
```

Run:
```bash
java StudentRegistration
```
